# Project 1: Automated Payment Reminder Agent (Zapier)

An automation that reads an Excel sheet of customers with outstanding balances and emails each one a payment reminder, then updates the sheet so nobody is reminded twice.

## Problem
Chasing overdue payments by hand is repetitive and easy to forget. This agent automates the reminders and keeps a record of who has already been contacted.

## Tools used
- **Zapier**: workflow automation
- **Excel**: customer data (connected to Zapier) [OneDrive / SharePoint / Google Sheets: confirm]
- **[Email app, e.g. Gmail / Outlook]**: sending the reminders
- **[AI step, if used, e.g. Zapier AI / ChatGPT]**: drafting the email text

## The data sheet

| Column | Description |
|--------|-------------|
| Customer Name | Name of the customer |
| [Email] | Where the reminder is sent |
| Due Amount | Outstanding balance |
| [Due Date] | [If present] |
| **Status** | `Pending` = reminder not yet sent, `Sent` = reminder already sent |

## How it works

1. **Trigger**: [describe: e.g. a schedule, or a new/updated row in the sheet].
2. **Find rows**: Zapier looks up rows where `Status = Pending`.
3. **Compose email**: the customer's name and due amount are inserted into the email body [or generated by an AI step].
4. **Send email**: the reminder goes to the customer's email address.
5. **Update sheet**: the row's `Status` is changed from `Pending` to `Sent`, so it is skipped on the next run.

```
Trigger → Find pending rows → Compose email → Send email → Update Status to "Sent"
```
